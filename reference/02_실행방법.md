# 실행 방법

## 로컬 실행

```bash
cd ~/Desktop/GPU/nvidia-hackathon
GAPCLOSER_LLM=tokenfactory make serve      # NEBIUS_API_KEY는 .env에서 읽습니다
```

| 주소 | 화면 |
|---|---|
| http://localhost:8000/ | 소개 (전체 흐름, 업무 3개 바로가기) |
| http://localhost:8000/console | AI 콘솔 (작동 원리, 성능 비교) |
| http://localhost:8000/studio | Studio (내 데이터, 업무 3개) |

흐름: 소개 → Studio(데이터 → 분석 → 결과: 보정된 시뮬레이터, 재학습, 내보내기) → AI 콘솔(원리와 성능 비교, 각 예시의 "이 상황을 Studio에서 직접 해 보기").
바로가기: `/studio?sample=stop-line#driving`(예시 열기), `/studio#factory`(업무 탭 열기).
| http://localhost:8000/api/docs | API 문서 |

- AI 없이 실행: `GAPCLOSER_LLM=none make serve` (질문 기능과 AI 진단이 꺼지고 계산 방식으로 동작합니다)
- 서버 종료: 실행한 터미널에서 Ctrl+C, 또는 `lsof -ti :8000 | xargs kill`

## 업무 선택

- Studio 첫 화면 위쪽 탭: 로봇 조작, 자율주행 차량, 제조 검사.
- 주소로 바로 열기: `/studio#robot`, `/studio#driving`, `/studio#factory`.
- 자율주행은 거리와 속도를 실제 크기로 표시하고, 내보내기에 CARLA 탭이 추가됩니다.

## 언어

- 기본은 영어입니다. 상단 EN/KO 버튼 또는 주소 뒤 `?lang=ko`로 한국어를 표시합니다.
- 선택한 언어는 브라우저에 저장됩니다.

## 질문 기능 (Studio 오른쪽 아래 "질문")

- NVIDIA Nemotron이 현재 화면의 결과를 바탕으로 답합니다. 한국어는 합니다체로 답합니다.
- 정답은 "정답 확인하기"를 누른 뒤에만 답변에 반영됩니다.
- 세션당 30회, 서버 전체 AI 호출 200회로 제한됩니다.

## 명령줄 사용

```bash
.venv/bin/python -m studio calibrate 기록.csv --llm tokenfactory --out runs/studio/결과
.venv/bin/python -m studio video 영상.mp4 --corners x1,y1,x2,y2,x3,y3,x4,y4
```

결과 폴더에 `calibration.json`, `newton_calibration.py`, `isaaclab_events.py`, `report.md`가 생깁니다. 자율주행 기록이면 `carla_calibration.py`도 생깁니다.

## 검증 명령

| 명령 | 내용 | 시간 |
|---|---|---|
| `make check` | 오프라인 테스트 전체 (네트워크, 크레딧 없음) | 약 2분 |
| `make prove` | 주요 수치를 모두 다시 계산해 `runs/proof/PROOF.md`에 기록 | 약 7분 |
| `make cross-engine` | 다른 엔진(MuJoCo)으로 만든 세계에서 채점 (`pip install -r requirements-eval.txt` 필요) | 약 1시간 |
| `make real-check` | 공개 실제 영상 52개로 추적과 마찰 법칙 확인 (약 310 MB 내려받기) | 약 15분 |
| `make prove-real` | 직접 찍은 영상과 기울기 시험 각도로 채점 (`reference/06` 참고) | 영상당 약 1분 |

## NVIDIA NeMo Agent Toolkit으로 실행

```bash
pip install -e integrations/nat_tether
nat run --config_file integrations/nat_tether/configs/tether.yml --input lab-bench          # Nemotron 사용
nat run --config_file integrations/nat_tether/configs/tether_replay.yml --input lab-bench   # 녹화된 실행 재생 (오프라인)
```

AI의 도구 호출이 하나씩 NAT 이벤트로 기록됩니다. 자세한 내용은 `integrations/nat_tether/README.md`에 있습니다.

## 공유 페이지 (기록 재생, 서버 불필요)

| 페이지 | 주소 |
|---|---|
| 소개 | https://claude.ai/artifact/MzMXqxdpWrrDNZq4HtFA3s |
| Studio | https://claude.ai/artifact/B8mi26WNiRJSiv9NTLoTjw |
| 콘솔 | https://claude.ai/artifact/WVBNfVMAzeNg71kDSFqYAf |

- 비공개 상태입니다. 다른 사람이 보려면 페이지의 Share 메뉴에서 공유해야 합니다.
- 서버 없이 미리 실행한 결과를 재생하므로 업로드, 가상 탁자 만들기, 질문 기능은 동작하지 않습니다.
- 예시 6개(로봇 3, 자율주행 2, 제조 검사 1)는 모두 NVIDIA Nemotron으로 실제 실행한 기록입니다.
- 공유 페이지끼리는 서로 연결되어 있습니다(소개 ↔ 콘솔 ↔ Studio). 공유 페이지에서는 Studio 업무 탭까지만 이동하고, 예시를 자동으로 열지는 않습니다.
