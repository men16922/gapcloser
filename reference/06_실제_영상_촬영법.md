# 실제 영상 촬영법 (15분이면 됩니다)

실제 물체 검증은 공개 벤치마크(EV-RealPhys, `make real-benchmark`)로 이미 했습니다. 직접 찍은 영상은 A4 용지를 기준으로 쓰는 휴대폰 경로까지 확인하는 선택 사항입니다. 아래대로 찍어서 Studio에 올리거나 파일을 전달해 주세요.

## 준비물

- 매끈한 책상이나 식탁 (길이 1 m 이상 비어 있으면 좋습니다)
- A4 용지 1장 (구김 없이)
- 작은 상자 1개: 손바닥보다 작고 단단한 것(예: 화장품 상자, 작은 택배 상자, 지우개 여러 개를 테이프로 묶은 것). **색이 진할수록** 추적이 잘 됩니다(빨강, 파랑, 주황 등).
- 폰과 거치대 (없으면 컵이나 책에 기대어 고정)
- 선택: 물티슈나 천 한 장 → 책상 중간에 깔면 "마찰이 다른 구간"이 됩니다

## 배치

```
   [폰]  ← 옆 비스듬히 위에서, 50 cm 정도 높이
     \
      \        A4 용지 (밀 방향 옆에 평평하게)
       \      ┌──────┐
  출발 ●──────┼──────┼──────→  상자가 미끄러지는 길 (60~80 cm)
              └──────┘
```

1. A4 용지를 상자가 지나갈 길 **옆에** 평평하게 둡니다(길 위가 아니라 옆).
2. 폰은 길과 종이가 **모두** 화면에 들어오도록, 옆에서 비스듬히 위를 향해 고정합니다. 촬영 중 폰이 움직이지 않게 합니다.
3. 천을 쓰면 출발점에서 30~40 cm 떨어진 곳부터 길 위에 깝니다.

## 촬영

1. 가능하면 **슬로모션(120fps)** 또는 **60fps**로 찍습니다. 30fps도 되지만 출발 속도가 6~15% 낮게 측정될 수 있습니다(잡음 많은 영상 시험에서 −6.5%).
2. 상자를 같은 출발점에서 손가락으로 **8~10번** 튕깁니다. 짧게, 중간, 길게 섞어서. 매번 상자가 **완전히 멈출 때까지** 기다린 뒤 손으로 제자리에 돌려놓습니다.
3. 손이 상자를 튕긴 뒤에는 화면 밖으로 빼 주세요(추적을 가리지 않게).
4. 1~2분이면 충분합니다.

## 올리는 방법

- `make serve` → http://localhost:8000/studio → 업무 "로봇 조작" → "영상이나 기록 선택"으로 파일을 올립니다.
- 종이 모서리는 자동으로 찾습니다(가상 영상 기준 평균 1~3 px 오차). 화면에서 초록 점이 종이 모서리와 맞는지 확인하고, 어긋나면 끌어서 옮깁니다.
- 상자 높이(cm)를 입력하고 추적 버튼을 누르면 AI 분석까지 이어서 진행되고, 끝나면 결과를 볼 수 있습니다.
- 실제 영상에는 정답이 없으므로, 결과의 오차 범위와 "NVIDIA Newton으로 검증"(같은 출발로 다시 실행한 오차)이 맞는지 판단하는 근거가 됩니다.

## 정답 마찰 재기: 기울기 시험 (영상 1개당 3분)

실제 영상에는 정답이 없어서, 마찰을 따로 재 두면 Tether의 결과를 채점할 수 있습니다. 필요한 것은 휴대폰 수평계(아이폰 "측정" 앱의 수평계)뿐입니다.

1. 영상에서 쓴 것과 **같은 표면**(책상 상판이 어렵다면 같은 재질의 판이나 두꺼운 책 표지)에 같은 상자를 올립니다.
2. 한쪽 끝을 천천히 들어 올리다가, 상자를 손가락으로 **살짝 밀었을 때 멈추지 않고 일정한 속도로 계속 미끄러지는** 각도를 찾습니다. 휴대폰을 판 위에 올려 각도를 읽습니다. 이 값이 θk입니다(미끄러질 때의 마찰 = tan θk).
3. 선택: 밀지 않아도 저절로 미끄러지기 시작하는 각도 θs도 적어 둡니다(정지 마찰, 항상 θk보다 큽니다).
4. 각 2~3번 재서 가운데 값을 씁니다.

물체와 표면을 바꿔 **3쌍**을 찍으면 충분합니다(예: 종이 상자/책상, 종이 상자/천, 플라스틱 케이스/책상).

## 결과 확인: 명령 하나

영상과 각도를 아래처럼 두고 `make prove-real`을 실행합니다. `video/real/` 폴더는 저장소에 올라가지 않습니다(방 안이 찍힌 영상은 내 컴퓨터에만 남고, 숫자만 기록됩니다).

```
video/real/box-desk.mov
video/real/box-cloth.mov
video/real/case-desk.mov
video/real/truth.json
```

```json
{
  "box-desk":  {"tilt_kinetic_deg": 21.5, "tilt_static_deg": 25.0, "object_height_cm": 5.0},
  "box-cloth": {"tilt_kinetic_deg": 28.0, "object_height_cm": 5.0},
  "case-desk": {"tilt_kinetic_deg": 17.0, "object_height_cm": 2.0}

```

결과는 `runs/proof/real_calibration.json`과 `runs/proof/PROOF.md` 9절에 들어갑니다. Tether의 마찰이 tan θk와 ±0.05 이내면 통과입니다.

## 결과를 더 믿을 수 있게 하는 방법 (선택)

- 천을 깐 영상과 안 깐 영상을 따로 찍어 비교하면, 천 구간을 찾아내는지 확인할 수 있습니다.
