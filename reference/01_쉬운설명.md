# 쉬운 설명

## 한 줄 요약

로봇이 연습하는 가상 세계(시뮬레이터)를 실제 세계에 맞게 고치는 AI입니다.

## 왜 필요한가

1. 로봇은 가상 세계에서 먼저 연습합니다. 기본 과제는 로봇 팔이 상자를 밀어 선에 세우는 것입니다. 같은 물리로 자율주행 차량(정지선 제동)과 제조 검사(푸셔가 부품을 검사 위치로 밀기)도 지원합니다([05_세가지_업무.md](05_세가지_업무.md)).
2. 실제 탁자는 가상 세계와 조금 다릅니다. 더 미끄럽거나, 일부가 젖어 있거나, 모터가 약하거나, 카메라가 기울어 있습니다. 그래서 실제로는 빗나갑니다.
3. Tether는 실제로 밀어 본 기록을 보고 무엇이 다른지 찾아 가상 세계를 고칩니다. 고친 가상 세계에서 다시 연습한 로봇은 실제 세계에서도 성공합니다.

## 무엇을 쓰는가

| 구성 요소 | 역할 |
|---|---|
| NVIDIA Newton | 물리 계산 (상자가 미끄러지는 움직임, 영상 렌더링) |
| NVIDIA Nemotron 3 Super (Nebius Token Factory) | 원인 추측, 실험 계획, 질문 답변 |
| NVIDIA Cosmos Reason 2 (선택, 로컬) | 영상에서 상자가 넘어졌는지 판단 |

숫자는 AI가 짐작하지 않습니다. AI는 원인의 종류를 고르고, 실제 값과 오차 범위는 수학 계산으로 구합니다.

## 화면 두 개

### 콘솔 (`/`)

- 모든 예시는 같은 과제입니다. 탭마다 다른 것은 실제 세계에 숨긴 원인입니다.
- 예: 젖은 구간, 힘 약한 모터, 휘어진 렌즈, 문제 3개 동시.
- "정답 보기"로 AI가 맞혔는지 확인합니다.
- "AI에게 문제 내기"에서 직접 숨길 값을 정할 수 있습니다.

### Studio (`/studio`)

세 단계입니다.

1. **데이터:** 업무(로봇 조작, 자율주행 차량, 제조 검사)를 고르고, 시작 방법을 고릅니다. 예시 보기, 가상 데이터 만들기(마찰과 다른 구간을 정하면 NVIDIA Newton이 영상이나 기록을 만듭니다), 내 데이터 올리기 중 하나입니다.
2. **분석:** 영상이면 A4 용지 모서리를 자동으로 찾아 거리와 카메라 위치를 계산하고, 각 시행의 출발 속도와 이동 거리를 잽니다. 추적이 끝나면 AI가 바로 원인을 찾기 시작합니다. 기록 파일은 바로 분석으로 넘어갑니다.
3. **결과:** 탭 세 개로 나뉩니다.
   - 보정된 시뮬레이터: 성공률 한 쌍(재학습 실측이 있으면 실측값), 다른 점과 오차 범위, 마찰 지도, 상자 겹쳐 보기, 남은 효과 점검, 다음 실험
   - 재학습: 세 가지 학습 조건의 학습 곡선과 숨겨진 환경 성공률
   - 내보내기: NVIDIA Newton 재현 검증, Newton·Isaac Lab 설정과 보고서(자율주행은 CARLA 설정도)

## 결과 화면 읽는 법

| 표시 | 의미 |
|---|---|
| 파란색/주황색 칠 | 미끄러운 곳/거친 곳 (μ는 마찰 값) |
| 회색 점선 상자 | 고치기 전 가상 세계의 예상 위치 |
| 초록 상자 | 고친 가상 세계의 예상 위치 (실제 물건과 함께 움직이면 정확) |
| 빗금 영역 | 아직 측정하지 않은 구간 |
| 오차 범위 | 실제 값이 들어 있을 범위 (좁을수록 확실) |
| 흰 마름모 | 정답 (정답 보기 후) |
| 다음 실험 | 아직 불확실한 곳. 여기까지 밀어 보면 결과가 더 확실해집니다 |

## 한계

- 물리는 "밀거나 제동해서 미끄러져 멈추는 동작" 하나입니다. 집기, 쌓기, 조향 같은 다른 동작은 지원하지 않습니다.
- 실제 폰 영상으로는 아직 검증하지 않았습니다. 지금까지 검증은 NVIDIA Newton이 만든 영상으로 했습니다.
- 상자가 넘어지는 경우는 계산에서 제외합니다.
