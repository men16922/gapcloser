## 2. 심사에서 나올 반론 Top 10과 대응

| # | 반론 | 대응 (실행 가능한 것만) |
|---|---|---|
| 1 | 전부 sim-to-sim, 정답이 후보에 포함 | 숨겨진 세계를 **MuJoCo**(설치 확인됨)로 생성하고, 후보 밖 효과(속도 의존 마찰, 경사, 구간 2개)를 넣어 교차 엔진 검증 |
| 2 | 유일한 실제 데이터 결과가 부정적 | 15분 촬영(사용자) + 경사 시험으로 정답 측정 → 실제 보정 성공 사례. 불가 시 IDPP 52개로 마찰 법칙 비교(아래 3) |

| 5 | 도메인 랜덤화 0%는 허수아비 | 랜덤화 폭(±10/20/40%) 스윕, 가장 좋은 폭과 비교 |

| 8 | NVIDIA 스택이 얕음 | 에이전트를 **NVIDIA NeMo Agent Toolkit**(`nvidia-nat` 1.9.0, PyPI 확인)로 실행, Cosmos를 "유효 시행 판정 게이트"로 승격하고 실제 영상에서 정밀도·재현율 보고, Isaac Lab 내보내기에서 구간·구동 이득을 주석이 아닌 실제 설정으로 |
| 9 | 포함률을 같은 분포에서 맞춤 | 오차 모델 고정 후 새 시드·나쁜 영상·교차 엔진 세계로 재평가, 항목별 신뢰구간 |
| 10 | 표본이 작음 | Nemotron 모델 비교 n = 15로 재실행(수십 센트), 재학습을 무작위 세계 24개에서 평균 ± 신뢰구간 |

## 4. S 수준 합격 기준 (점검 가능한 형태)

1. **실제 데이터 1건 이상 끝까지 성공**: 물체-표면 3쌍 이상에서 Tether의 μ가 경사·당김 시험 정답과 ±0.05 이내, 영상 커밋, `make prove-real`로 재현
2. **교차 엔진·후보 밖 세계 24개 이상**: 포함률 ≥ 85%, 후보 밖 효과는 "설명 안 됨"으로 표시하고 엉뚱한 값을 확신하지 않음
3. **에이전트 필요성 증명 또는 정직한 재포지셔닝**: 후보 밖 단계(n ≥ 15)에서 Nemotron이 고정 라이브러리를 겹치지 않는 신뢰구간으로 이김
4. **공정한 랜덤화 비교**: 최적 폭 랜덤화를 이김
5. **접촉 기반 발사**에서도 결과 유지
6. **NVIDIA 스택**: NeMo Agent Toolkit 위에서 에이전트 실행, Cosmos 게이트의 정밀도·재현율 공개
7. **하나의 제품, 하나의 디자인**: 3개 화면 공통 디자인 시스템, Studio 3단계, 막다른 버튼 0개, 결과 헤드라인 1개
8. **추적 가능성**: 모든 숫자가 proof.json에서 생성, 첫 30초에 "실제 영상 → 보정된 Newton → 더 나은 정책"

### W2. NVIDIA 스택
- NeMo Agent Toolkit으로 도구 에이전트 실행(Python 3.13 호환성 먼저 확인, 불가 시 별도 3.12 가상환경)
- Cosmos를 유효 시행 게이트로(미끄러짐 / 굴러감 / 넘어짐 / 손 접촉)
- Isaac Lab 내보내기: 구간 마찰·구동 이득을 실제 설정 항목으로

### W3. 제품·디자인
- **하나의 제품**: Studio가 제품, 콘솔은 "Agent Lab(근거)"로 이름과 역할 정리, 소개는 랜딩
- **공통 디자인 시스템**: tokens.css(회색 단계 하나, docs/design/REFERENCE.md 기준), 버튼·헤더·브랜드 공용, build.py가 인라인
- **Studio 6단계 → 3단계**: 데이터 → 분석(측정·진단 자동 진행, 스트리밍) → 결과(보정 / 재학습 / 내보내기 탭). "추적 시작", "진단 실행" 같은 중간 버튼 제거
- **결과 헤드라인 하나**: 모델 예측이 아닌 재학습 실측 기준 "숨겨진 세계 성공률 0% → 100%", 불확실성은 보조
- **3D 장면을 Studio로**: 콘솔의 three.js 뷰어로 보정 전/후 고스트 비교
- **기록 모드 동일성**: 단계별 검증·재학습 기록(막다른 버튼 제거)

### W4. 엔지니어링 (감사 결과 순위)
1. 서버 영어 문장 ↔ 한국어 매핑 누락을 잡는 테스트 + 누락 보완 (2~3시간)
2. 세션 저장소 잠금·바쁜 세션 보호·타임아웃·실패 정리·임시 폴더 삭제 (4~6시간)
3. 죽은 코드·오래된 문서 정리, TablePolicy 중복 제거 (2~3시간)
4. 단위 변환 서버 한 곳으로(클라이언트 toView 제거), 메시지는 코드+파라미터 (8~12시간)
5. 분야·예시 정의를 domains.py 하나로, build.py가 주입 (4~6시간)
6. studio_api를 라우터 모듈로 분리, SSE 공용화, server→eval 의존 제거 (4~6시간)
7. 공통 tokens.css / i18n.js / 헤더 (5~8시간)
8. studio.html JS 모듈 분리, 세션 단위 상태, 모든 요청을 be 경유 (10~16시간)
